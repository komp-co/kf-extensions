# The KFlat marks

| File | What it is |
|---|---|
| `kiwi.svg` | The paper kiwi: the logo, with a K in its folds |
| `kiwi-tile.svg` | The kiwi on a fern-green tile, the app and marketplace icon |
| `k.svg` | The folded K, the mark for source files |

The editor icons built from them live in `../vscode/icons`.

## Colours

The kiwi is brown; fern green is everything else: the K, the tile and the
badges.
